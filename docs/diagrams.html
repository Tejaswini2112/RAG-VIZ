2. RAG Query Pipeline 9 Steps

Each step streams to the UI as it completes. The CRAG evaluator is the branching point — it decides whether to use retrieved documents, trigger a live web search, or both. The verifier can trigger a single retry if the answer fails faithfulness or relevance checks.
